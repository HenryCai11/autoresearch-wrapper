# Autoresearch × GEO — 50-second demo script

## 00:00–00:06 — Hook

网站上线，只是起点。真正的问题是：Agent 会不会找到你？我们把 GEO 变成一个可测量、可回滚、会学习的优化循环。

## 00:06–00:13 — Define

每次运行先锁定三个输入：要修改的仓库、要提升的目标，以及唯一的评分命令。

## 00:13–00:21 — Map

Wrapper 扫描代码和内容，构建依赖图。节点记录缺口、修改成本和可达结果，边描述一次改动会影响哪里。

## 00:21–00:29 — Explore

Agent 从当前最佳版本创建独立工作树，探索多个候选。每个修改都能单独测量，失败直接丢弃，过程证据完整保留。

## 00:29–00:37 — Measure

Inner loop 快速检查结构与可达性；Outer loop 调用真实搜索，统计提及、归因、引用和排名。Outer 才决定候选是否晋级。

## 00:37–00:45 — Frontier

候选分数可以上下波动，但 frontier 只记录历史最佳。超过 incumbent 就 Keep，否则 Discard，然后从最佳版本继续探索。

## 00:45–00:50 — Close

扫描、推理、修改、搜索、决策，再循环。让每一次 vibe coding 都能被测量、比较和复现。
