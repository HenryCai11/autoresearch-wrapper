# Autoresearch × GEO V2 — 42-second graph-first demo

## 00:00–00:03.5 — Hook

GEO 优化，不是改一个页面。是找到整张依赖图里的阻塞点。

## 00:03.5–00:10 — Build

Wrapper 扫描仓库，把页面、结构化数据、外部证据和搜索结果抽象成可修改节点。

## 00:10–00:16.5 — Connect

它识别静态引用、生成关系、语义支撑和真实检索四类依赖，构建从代码到 Agent 回答的可达路径。

## 00:16.5–00:23 — Diagnose

然后沿路径排查阻塞。综合缺口、下游影响、路径重要性和修改成本，定位全局优先级最高的问题节点。

## 00:23–00:29.5 — Mutate

Agent 可以增加节点、重写节点或移动关系边。每种方案进入独立工作树，形成可比较的候选依赖图。

## 00:29.5–00:36 — Iterate

Inner loop 快速筛选，真实搜索 Outer loop 决定 Keep 或 Discard。下一轮始终从当前最佳图继续探索。

## 00:36–00:42 — Close

扫描、建图、诊断、修改、评测，再循环。让 Agent 曝光的每一次变化都可解释、可测量、可回滚、可复现。
