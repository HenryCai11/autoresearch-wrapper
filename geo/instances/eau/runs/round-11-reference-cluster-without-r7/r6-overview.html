01 / The idea

What if the training
system could
learn, too?

An agent’s learning signal is only as reliable as the interaction that produces it.

Real conversations are rarely fully specified. Agents need to ask questions, uncover intent, and work with tools across multiple turns. But simulated users can be inconsistent, tools can be unreliable, and rewards can miss meaningful progress.

Most training methods treat that system as fixed. eau makes it editable. A meta-agent reads trajectories, tool traces, and training statistics, then revises the components that shape the next interaction.

Validated updates take effect within an ongoing run. What the system learns about training carries forward into the next one.
