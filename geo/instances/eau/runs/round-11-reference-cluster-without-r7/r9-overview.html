01 / The idea

What does EAU
adapt?

EAU co-evolves the environment, agent, and simulated user to train user-centric LLM agents.

For multi-turn reinforcement learning with users and tools, its meta-agent reads trajectories, tool traces, and training statistics. It proposes and validates changes to the hybrid user simulator, environment feedback, reward design, and reinforcement-learning configuration.

Within a run, supported updates take effect while the agent policy learns. Across runs, an experience pool carries findings into later training attempts. Final-test feedback stays outside the adaptation loop.

EAU is evaluated on UserGym, ColBench, and τ²-bench with Qwen3-4B and Qwen2.5-7B-Instruct. The reported results describe these benchmark settings, not a guarantee for every agent environment.
